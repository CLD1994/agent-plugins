# 04: 实现严格 Draft 根事实来源

**What to build:** 实现根事实来源的真实文件系统适配器，为索引候选计算提供完整、稳定且不越过 Draft 词法边界的 Markdown 和目录事实。

**Blocked by:** 03: 建立纯链接索引领域引擎.

**Status:** ready-for-agent

- [ ] 遍历完整 Draft 根并排除整个 `.draft` 内部目录，记录每个遍历目录的直接成员名称和节点类型。
- [ ] 只读取普通 `.md` 文件，不跟随或读取符号链接；非 Markdown 节点只影响目录事实，不读取其正文。
- [ ] 每次严格扫描读取全部覆盖 Markdown 并计算 SHA-256；inode、size 和 mtime 只能作为单次进程内变化探针，不能证明正文未变化。
- [ ] 上层提供的已解析事实只有在路径和重新计算的 SHA-256 都匹配时才能复用，并且不能跳过正文读取和摘要比较。
- [ ] 任一 Markdown 无法读取、求摘要、UTF-8 解码或提取 CommonMark 链接时，不产生完整索引候选，也不把该文件解释为没有链接。
- [ ] 扫描期间观察到文件或目录事实再次变化时返回不稳定结果，不发布混合时点快照，也不在内部无限重试。
- [ ] 真实文件系统集成测试覆盖 managed page、未受管理 Markdown、非 Markdown、宽目录、符号链接、不可读文件、非 UTF-8、解析失败和扫描期间变化。
