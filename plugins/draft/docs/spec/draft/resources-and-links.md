# 资源与链接

## 行为合同

正文链接通过 `ResourceIdentity` 区分 `page`、`local`、`external` 及 `present`、`missing`、`unavailable`、`unchecked`、`invalid`。结构操作使用根内全部 Markdown 的链接事实闭包；移动映射统一更新出站、入站和同批交叉链接，锚点保留。

页面子树只拥有受管理 Markdown，不因物理邻接拥有图片、附件或普通目录；非 Markdown 资源原地保留。

## 失败与恢复

UTF-8 解码、CommonMark 提取、源码对齐、路径分类或映射无法证明时，相关结构操作零写。缺失目标只要词法身份可证明，不自动成为闭包错误。
