# 行为合同登记

本页登记每个 Contract-ID 到一个逻辑 Target、完整 Provenance、Supersedes、Consumers、Verification 和 `Unresolved / diagnostic` 的当前关系。Target 列列出其有序、精确的成员 locator；行为仅由 Target owner 正文拥有。本页是登记表，不是行为 authority。当前每一行的 `Unresolved / diagnostic` 都是 `none`；未来候选如不能满足治理核验，才在该列记录具体诊断并停止合入。

## QueryOutcome owner 分工

下表只登记 QueryOutcome 各责任边界的唯一 owner，不复制任何字段表、值域或排序表。公共
wrapper 的结构由 R-ERRORS 保持；集合及其领域内容由 D-QUERY 保持；Check 诊断成员由
P-DIAGNOSTICS 保持。其他页面只能沿 owner 链接读取行为。

| QueryOutcome 责任组件 | 唯一 owner | 允许保留的边界 |
| --- | --- | --- |
| 最外层 wrapper（含 `result_type`/`query`/`complete`、公共成员省略规则）、`items`/`blockers` 互斥、`severity_counts` 的公共形状与出现条件，以及通用 Blocker 形状 | [R-ERRORS](../runtime/errors-and-observability.md#公共结果错误与可观测性) | 只定义公共结果外壳；不定义查询集合成员、Check 计数基数或查询专属 blocker 规则。 |
| 查询集合及其完整性、`entries`/`total`/`next_cursor`、精确总数、`count_only`/page 单项语义、分页和非 Check Entry | [D-QUERY](../draft/query-check-and-output.md#查询行为合同) | 定义查询来源/完整性、集合内容、非 Check 条目、cursor 绑定和非 Check 排序；不重列公共 wrapper。 |
| 查询 blocker 的领域触发、专属 details 和排序 | [D-QUERY](../draft/query-check-and-output.md#查询行为合同) | 只定义查询领域事实及其集合投影；通用 Blocker 外壳回链 R-ERRORS。 |
| Check Entry、severity、code-specific details、Check 排序和计数基数 | [P-DIAGNOSTICS](../draft/query-check-and-output.md#check-诊断合同) | 定义 Check 诊断结构、排序及未过滤/过滤集合的计数口径；`severity_counts` 的公共形状与出现条件回链 R-ERRORS，查询集合回链 D-QUERY。 |
