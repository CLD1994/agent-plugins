# Draft 领域词汇

Draft 在单个根目录中管理 Markdown 页面网络，并以确定的路径、关系和链接规则维护其结构。

## 词汇

- **Draft 根**：承载一个 Draft 的页面、关系和根状态的单一工作范围。
- **Draft marker**：记录 Draft 根身份与根状态的唯一领域记录。
- **候选根（candidate root）**：尚未完成全部检查、仍允许继续整理内容的 Draft 根。
- **正式根（registered root）**：已经完成登记的 Draft 根；业务写入要求完整、可认证的领域事实。
- **Trash**：已获回收授权但仍被保留、可在 7 天恢复窗口内申请恢复的内容。
- **Restore**：在恢复窗口内使 Trash 内容回到 Draft 内容中的行为；冲突或证据不足时不覆盖、不猜测合并。
- **受管理页面**：属于 Draft 页面命名空间的 Markdown 文件；资格由路径决定，不取决于正文是否完整。
- **叶页面**：不拥有子页面命名空间的普通受管理页面。
- **枢纽页面**：以自身 `index.md` 表达并拥有直接子页面命名空间的受管理页面。
- **未受管理 Markdown**：位于 Draft 根内但不属于页面命名空间的普通 Markdown 文件。
- **页面纳管**：未受管理 Markdown 因路径移动进入页面命名空间的变化；不等同于补齐页面协议。
- **枢纽升格**：将叶页面转换为枢纽页面并改挂明确指定的子页面。
- **资源身份（`ResourceIdentity`）**：链接目标的规范身份，用于判断不同链接表达是否指向同一资源。
- **链接事实闭包**：结构变更需核对的全部页面及链接事实，以证明链接关系没有遗漏。
- **链接索引**：依据页面和链接事实提供查询的派生资料；页面与链接事实才是权威来源。
- **恢复未决**：尚未收敛到可安全继续其他变更的持久现场，叠加在候选根或正式根之上。
- **操作恢复**：依据已记录事实完成或回退恢复未决变更，不以猜测替代已知事实。
- **受协调 writer**：遵守 Draft 共同写入协议的写入者。
- **耐久失败**：已决定的变更无法可靠保存；在恢复前不得当作已完成。

实现细节、错误清单和页面行为合同见 [规格入口](docs/spec/index.md)，不在本词汇表重复维护。
