# Draft 领域词汇

Draft 在单个根目录中管理 Markdown 页面网络，并以确定的路径、关系和链接规则维护其结构。

## 词汇

- **现行设计规格**：已确认且当前有效的行为定义，是实施与验收的设计依据；其生效不表示代码已经实现。
- **变更规格**：描述某项工作拟增加或调整的行为及验收的增量文档。
- **设计依据**：一项任务所引用的现行设计规格，说明该任务遵循的行为规则。
- **Draft 根**：承载一个 Draft 的页面、关系和根状态的工作范围。
- **Draft marker**：记录 Draft 根身份与根状态的领域记录。
- **候选根（candidate root）**：处于内容整理阶段的 Draft 根。
- **正式根（registered root）**：已登记并作为业务使用边界的 Draft 根。
- **Trash**：从 Draft 内容中回收后仍被保留的内容。
- **Trash 身份**：与一份 Trash 内容关联、供后续定位的不透明标识。
- **Restore**：使 Trash 内容回到 Draft 内容中的恢复行为。
- **Handoff**：把 Trash 内容交给外部接收方的生命周期行为。
- **受管理页面**：属于 Draft 页面命名空间的 Markdown 页面；资格由路径决定，不以正文完整性为准。
- **页面头部信息**：与受管理页面正文分离、用于描述页面元数据的头部内容。
- **结论生成状态**：描述结论制品是否已经由 Draft 取得所有权的领域事实。
- **叶页面**：不拥有子页面命名空间的受管理页面。
- **枢纽页面**：拥有直接子页面命名空间的受管理页面。
- **未受管理 Markdown**：位于 Draft 根内但不属于页面命名空间的 Markdown 文件。
- **页面纳管**：把未受管理 Markdown 纳入页面命名空间的领域变化。
- **枢纽升格**：把叶页面转换为拥有子页面命名空间的枢纽页面。
- **资源身份**：归一化后的链接目标标识，用来判断不同链接表达是否指向同一资源。
- **受保护内部目标**：指向 Draft 私有区域的正文链接目标。
- **链接事实闭包**：与结构变更相关的页面及链接事实集合。
- **父子导航**：表达页面父子关系的导航概念。
- **链接索引**：依据页面与链接事实形成的查询资料。
- **恢复未决**：未完成操作留下的持久恢复现场。
- **操作恢复**：处理恢复未决现场的恢复行为。
- **操作身份**：与一次逻辑操作关联、用于区分重复发起与新操作的不透明标识。
- **查询来源范围**：某类查询可读取的 Markdown 来源范围。
- **恢复受阻**：表示恢复现场暂时不能安全继续的诊断状态。
- **恢复收敛**：恢复未决现场已经处理完毕、不再阻止后续操作的领域事实。
- **查询游标**：表示查询分页位置的不透明身份。
- **检查诊断**：针对可验证问题形成的诊断事实。
- **受协调 writer**：遵守 Draft 共同写入协议的写入者。
- **耐久失败**：已决定的变更未能可靠持久化的失败状态。

实现细节、错误清单和页面行为合同见 [规格入口](docs/spec/index.md)，不在本词汇表重复维护。
