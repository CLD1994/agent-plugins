# 匿名模型比较

只在用户明确批准匿名比较后阅读和执行。它适用于无法可靠判断最低可用模型层级，或常规升级后的证据仍不能回答该问题；缺少历史经验不是理由。比较前，Main 记录用户批准、比较目标、参加层级、当前模型映射、起始基线、行为契约、共享约束和验收条件。

## 形成隔离路线

比较的是整项任务的完整切片序列，不是第一个切片的单次表现。

- 每个参加层级形成一条完全隔离的路线。路线各自保留 worktree、分支、已验证的累计结果和记录。
- 每条仍在比较的路线在同一任务切片上工作，遵守相同的当前行为、共享约束和验收条件。
- 同一条路线中的执行、事实核对、评审和整合仍分别按其工作角色调度；路线之间不读取、不复用、不拼接产物。
- 每个切片及其独立评审设同步点。提前通过的路线等待；评审未通过的路线只在当前切片重试；所有仍有效路线都通过或被淘汰，才共同进入下一切片。
- 一条路线在同一切片连续三次有效的“已完成但评审未通过”后淘汰。停止并报告不伪装成评审失败。

|路线事件|Main 的处理|
|-|-|
|路线停止并报告，且原因是共同任务问题|暂停全部路线，统一更新任务说明后再决定继续|
|路线停止并报告，且原因只在该路线|只有出现有意义变化时才重派；否则以“未完成退出”淘汰该路线|
|Main 要改变未来切片的行为或验收|暂停全部路线，向所有仍有效路线发出相同变化后再继续|
|整合或后续切片发现早期问题|确定受影响阶段，让所有仍有效路线回到该阶段重新验证|

公平性要求相同的行为契约、证据标准和执行机会，不要求路线产物具有相同文件结构或实现。至少一条路线完成全部切片，且其他路线也完成或淘汰后，比较才结束。任何时候不得把不同路线的成功切片拼成一个候选。

## 比较期间的补充与恢复

所有仍有效路线收到共享更新时，Main 对每条路线使用同一个全局补充版本、同一个共享约束版本和同一个失败连续性保留或新建决定。每条路线仍使用自己的本地消息回合和 checkpoint；Main 调度记录保存全局版本到各路线本地路径的映射。

只影响单一路线切片的非共享补充只能澄清该路线的局部证据或处置，不能改变其他路线的记录，也不能改变共同的行为、授权、共享约束或验收条件。若补充会改变这些共同条件，它是共享更新，必须暂停并同样投递给所有仍有效路线。

每条路线的最大编号 checkpoint 必须独立保留当前已应用的全局补充版本、当前共享约束、处置和逐条补充事件。匿名比较不改变 checkpoint、上下文压缩或失败连续性的普通规则。

## 匿名评估与采用

评估开始前，由 Main 只向评估者提供中性路线材料。遮蔽模型名称、模型层级、worktree 与分支命名、提交作者、日志身份、文件排序和其他来源元数据。目标是让评估者看不到声明的模型身份；不承诺排除从写作风格推测来源。

Main 可以按可独立判断的问题切分评估。若有多个评估者，再由一名新的顾问级最终评估者读取各评估结论、整体状态和必要接缝，在身份揭示前固定结论。评估者需要额外事实时，通过 Main 派中立事实核对者；评估者不实施、整合或重写候选。

多个层级的完整路线都通过时，先判断较高层级候选的额外内容是否是现有行为契约和项目规则的必要条件：

|判断|采用结果|
|-|-|
|额外内容是必要条件|较低层级候选没有真正通过，继续按满足条件的路线判断|
|额外内容不是必要条件|采用通过验收的最低层级完整路线，不为额外价值付费|

执行级和思考级路线均失败且没有顾问级路线时，派新的顾问级执行 agent 从完整当前任务开始。顾问级路线也累计三次有效失败，或最终结果仍无法判断时，停止并询问用户。

只有身份揭示前已固定结论的独立评估者，才能把匿名比较和模型难度结论写入 docs/agents/yuna.md。写入后才可揭示身份；该记录不能修改任务规格、候选实现或用户授权。

## 状态模型验证例

某个切片中，一条路线先通过独立评审时在同步点等待，另一条路线在该切片按失败连续性重试；后者通过或被淘汰前，前者不能进入下一切片。比较结束时若多个模型层级都完成完整路线，先按“匿名评估与采用”的必要条件表判断，再采用最低真正通过的层级。期间的共享更新对所有仍有效路线使用同一全局补充版本、共享约束版本和失败连续性决定；只给某一路线切片的非共享补充保留在该路线的 checkpoint，不改变其他路线记录。
