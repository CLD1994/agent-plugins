# 匿名模型比较

只在根级 Main 获得用户明确批准，或父任务在任务单/补充中按 [角色、加载和权限](../SKILL.md) 的窄授权规则明确写出授权来源、命名对象、允许结果或动作、必须保持的不变量和执行条件后阅读和执行。它适用于无法可靠判断最低可用模型层级，或常规升级后的证据仍不能回答该问题；缺少历史经验不是理由。比较前，负责该范围的调度者记录批准依据、比较目标、参加层级、当前模型映射、起始基线、行为契约、共享约束和验收条件。

## 形成隔离路线

比较的是整项任务的完整切片序列，不是第一个切片的单次表现。

- 每个参加层级形成一条完全隔离的路线。路线各自保留 worktree、分支、已验证的累计结果和记录。
- 每条仍在比较的路线在同一任务切片上工作，从同一份冻结的共同输入开始，并遵守相同的当前行为、共享约束和验收条件。
- 同一条路线中的执行、事实核对、评审和整合仍分别按其工作角色调度；路线之间不读取、不复用、不拼接产物。
- 每个切片及其独立评审设同步点。提前通过的路线等待；评审未通过的路线只在当前切片重试；所有仍有效路线都通过或被淘汰，才共同进入下一切片。
- 一条路线在同一切片连续三次有效的“已完成但评审未通过”后淘汰。停止并报告不伪装成评审失败。

|路线事件|负责该范围的调度者的处理|
|-|-|
|路线停止并报告，且原因是共同任务问题|暂停全部路线，统一更新任务说明后再决定继续|
|路线停止并报告，且原因只在该路线|只有出现有意义变化时才重派；否则以“未完成退出”淘汰该路线|
|负责该范围的调度者要改变未来切片的行为或验收|暂停全部路线，向所有仍有效路线发出相同变化后再继续；若变化超出继承范围，先向父级报告|
|整合或后续切片发现早期问题|确定受影响阶段，让所有仍有效路线回到该阶段重新验证|

公平性要求相同的行为契约、证据标准和执行机会，不要求路线产物具有相同文件结构或实现。至少一条路线完成全部切片，且其他路线也完成或淘汰后，比较才结束。任何时候不得把不同路线的成功切片拼成一个候选。

## 比较期间的补充与恢复

所有仍有效路线收到共享更新时，负责该范围的调度者对每条路线使用同一个本层补充版本、同一个共享约束版本和同一个失败连续性决定。实际改变共享约束时，所有受影响路线都从更新后的冻结共同输入和执行级开始新的失败连续性。每条路线仍使用自己的本地消息回合和 checkpoint；该调度者的记录保存本层版本到各路线本地路径的映射。

只影响单一路线切片的非共享补充只能澄清该路线的局部证据或处置，不能改变其他路线的记录，也不能改变共同的行为、授权、共享约束或验收条件。若补充会改变这些共同条件，它是共享更新，必须暂停并同样投递给所有仍有效路线。

每条路线的最大编号 checkpoint 必须独立保留当前已应用的本层补充版本、当前共享约束、处置和逐条补充事件。匿名比较不改变 checkpoint、上下文压缩或失败连续性的普通规则。

## 匿名评估与采用

评估开始前，由负责该范围的调度者只向评估者提供中性路线材料。遮蔽模型名称、模型层级、worktree 与分支命名、提交作者、日志身份、文件排序和其他来源元数据。目标是让评估者看不到声明的模型身份；不承诺排除从写作风格推测来源。

负责该范围的调度者可以按可独立判断的问题切分评估。若有多个评估者，再由一名新的顾问级最终评估者读取各评估结论、整体状态和必要接缝，在身份揭示前固定结论。评估者需要额外事实时，通过负责该范围的调度者派中立事实核对者；评估者不实施、整合或重写候选。

多个层级的完整路线都通过时，先判断较高层级候选的额外内容是否是现有行为契约和项目规则的必要条件：

|判断|采用结果|
|-|-|
|额外内容是必要条件|较低层级候选没有真正通过，继续按满足条件的路线判断|
|额外内容不是必要条件|采用通过验收的最低层级完整路线，不为额外价值付费|

执行级和思考级路线均失败且尚无顾问级执行路线时，负责该范围的调度者可以在已经获准的匿名比较中，按任务单将顾问级模型另行记录为执行角色。它从与其他层级相同的冻结共同输入开始一条独立路线，生成候选、接受独立评审，并按普通执行结果累计有效失败。模型层级不会扩大该路线的角色或权限；授权仍以 [角色、加载和权限](../SKILL.md#角色加载和权限) 为准。

顾问分析是另一种工作角色。它按 [运行、结果和升级](../SKILL.md#运行结果和升级) 的规则诊断连续失败，产物不作为执行候选，也不消耗顾问级执行路线的失败次数。顾问级执行路线累计三次有效失败，或最终结果仍无法判断时，停止并向根级 Main 报告，由根级 Main 询问用户；获得该命题具体决定权的父级只能在任务单或补充明确写出的对象、允许结果、不变量和条件内处理。

只有身份揭示前已固定结论的独立评估者，才能把匿名比较和模型难度结论写入 docs/agents/yuna.md。写入后才可揭示身份；该记录不能修改任务规格、候选实现或用户授权。嵌套调度者将本层结论交给父级，由根级 Main 负责全局经验记录。

## 状态模型验证例

某个切片中，一条路线先通过独立评审时在同步点等待，另一条路线在该切片按失败连续性重试；后者通过或被淘汰前，前者不能进入下一切片。比较结束时若多个模型层级都完成完整路线，先按“匿名评估与采用”的必要条件表判断，再采用最低真正通过的层级。期间的共享更新对所有仍有效路线使用同一本层补充版本、共享约束版本和失败连续性决定；只给某一路线切片的非共享补充保留在该路线的 checkpoint，不改变其他路线记录。
