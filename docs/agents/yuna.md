# subagent 调度经验

本文件是经过独立评估的任务难度与模型调度经验的唯一权威记录。

本文件只提供已经验证的经验，不是任务难度的完整分类器，也不取代 `Main Agent` 对当前任务的判断。

评估者只能记录已经完成的匿名评估或任务难度升级的结果，不得在此修改任务规格或候选实现。

## 难度等级

|等级|判定依据|
|-|-|
|执行级|执行者级模型在三次执行内稳定满足验收条件|
|思考级|执行者级模型失败，思考者级模型从原始基线重新实施后在三次内满足验收条件|
|顾问级|执行者级模型和思考者级模型均失败，需要顾问级模型的指导或亲自执行才能满足验收条件|
|人类介入|顾问级模型执行三次仍失败，或结果无法可靠判断|

难度按完成任务所需的最低稳定干预层级判定，不按具体模型名称、单次表现或主观印象判定。

## 记录

不描述具体任务细节，将具体任务高度抽象泛化。当记录与实际不符时，根据实际情况更新或派生记录。

### 权威分散的跨来源审查与规格收敛

#### 任务特征

- 当前行为分散在多份历史规格、候选文档、实现和测试中，且其中可能混有未经签署的推论。
- 需要同时判断既有权威是否已经给出答案、候选是否发生漂移，以及真正需要人类决定的语义。
- 预期产物包含跨对象矩阵或全量覆盖清单，容易把事实发现、权威裁决和实现观察合并成一次宽委派。

#### 难度与调度结论

不要直接为整个组合任务评定模型层级。一次委派同时要求全库发现、选择权威、建立完整矩阵并综合决策时，任务边界没有自然终点；提升模型层级不能补全不稳定的权威上下文，通常只会继续增加读取和推理成本，也不能据此证明模型能力不足。

Main Agent 先建立待判定命题与覆盖清单，再按以下顺序调度：

1. **权威切片**：一个可证伪命题、固定权威来源清单和停止条件。结果只分类为“已有唯一答案、权威冲突、权威未定义”，并提供精确定位和最小反例。
2. **实现观察切片**：仅在权威未定义或人类需要理解选择后果时启动，只读取与同一命题直接相关的实现和测试；实现现状不参与权威裁决。
3. **整合**：Main Agent 汇总命题状态，已有答案用于清除漂移，冲突或未定义项才形成供人类选择的最小前沿。

真正需要穷举时，先机械建立矩阵骨架，再把互不重叠的行分派给不同 Agent；最后单独审查跨行接缝。每个 Agent 只完成自己的闭合切片，不重复重建全局上下文。

#### 分片交接与边界

- 执行者和独立 reviewer 各自使用专属 plan 文件。初始 packet 只包含一个命题、固定基线、该命题所需的 owner 摘录、验收条件和本片 checkpoint 路径；不带入其他切片、全局调度资料或未授权结果。
- 初始 packet 的命题、基线和已经发出的 owner 摘录不可变。执行计划可以在同一 plan 文件中按序追加补充，但不得偷换命题或基线。发现 packet 遗漏或错误时，直接追加更正并通过 follow-up 通知当前执行者，不停止执行者或另建替代 plan；每次 follow-up 原文追加到 `/tmp/agents/<session>/subagent/<subagent_name>/main-<trun>.md`。
- reviewer 也沿专属 packet 工作；需要额外事实时由 Main Agent 按同一文件和角色边界补充，不自行读取全局计划、其他切片或未授权结果。

#### 增量记录与上下文恢复

- 大型复审按可验证命题拆成小步骤，边执行边记录；每完成一个命题就写入 checkpoint，不把证据和状态留到最后的总报告。
- checkpoint 是执行者的可恢复工作笔记，不只是进度元信息。每完成一个有边界的小步骤，都要把已证事实、精确证据定位、事实如何支持或违反命题/不变量、被排除的解释或最小反例、未决项及其影响写入 checkpoint；重要结论不得延迟到最终报告才记录。
- 每个 checkpoint 至少记录固定基线、已覆盖范围、权威来源、不变量、证据定位、结论、未决项和 `next_cursor`；游标必须指向下一项未完成的命题或动作。最终报告应汇总这些笔记，不能替代它们；尚未核验的判断明确标为 pending，不用摘要补全。
- 发生上下文压缩、会话恢复或执行者更换时，不丢弃当前会话；先重读事项账本、专属 plan 和最近的 checkpoint，再按 `next_cursor` 继续。已记录的事实和证据不因压缩而丢弃，也不凭摘要补全缺失内容。
- 只有 checkpoint 缺失或固定基线漂移时，才重新派遣或重建相应切片；其他情况保持切片边界和已覆盖状态继续推进。
- 暴露、压缩或中断在完整执行并完成独立复审前，不计为有效失败尝试。
- 反模式包括：一个 Agent 连续重读全库；只在最后写总报告；把上下文耗尽误判为语义失败；把未覆盖范围当作 PASS。未覆盖或未决命题必须显式保留其状态。

#### 暴露、角色违规与弃用

- 仅共享路径或文件名暴露时标记为 `exposed / 未核实`，不自动推导污染或作废。只有已确认实际读取、引用非本片信息、越过角色边界，或影响无法排除时，才标记为 `polluted / untrusted`。
- 加载作用域内 `AGENTS.md` 明令禁止的 skill 属于角色违规；立即停止并弃用该切片。不要把所有 skill 加载或 agent 间 collaboration 一概设为禁令，只有越出 packet、文件或角色边界时才处置。
- 用户决定“直接弃用”时，默认物理删除可重建的 worktree、分支、未提交 diff 和未采信产物。删除可能影响审计、法律/合规、恢复、共享祖先或其他不可逆后果时，先交由人类或获人类授权的顾问决定；不可重建的治理或审计记录保留并明确标记为弃用。

#### 模型选择

- 精确来源核对和局部实现观察优先使用执行级模型。
- 跨命题依赖、状态模型和最小决策前沿需要独立推理时使用思考级模型。
- 只有在相同、完整且稳定的切片上下文中形成有效失败后，才依据通用升级规则判断是否需要更高层级；宽任务无产出不是升级证据。

#### 完成判据

- 覆盖清单中的每个命题都有唯一状态和证据定位。
- 每个 Subagent 产物只回答一个命题；旁支只登记所需上下文，不自行扩展。
- 权威来源已有答案时不启动运行时调查；代码和测试不会反向批准产品语义。
- 交给人类的前沿只包含会改变可观察行为且无法由现有权威唯一推出的选择。
