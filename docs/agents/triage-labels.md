# 分诊操作

本地任务的 `Status` 表示分诊阶段和需要谁参与。合法取值及含义统一见 [任务字段](../../plugins/draft/docs/spec/governance/feature-specs.md#任务字段)，任务生命周期与执行前检查也由该设计规格定义。

当 skill 要求应用分诊标签时，在对应 `.scratch` 任务头部更新一次 `Status`，把具体缺口或需要的决定写入正文；其他文档通过链接读取该任务。完成状态由 `Tracker-State` 和关闭记录表达。

分诊为 `ready-for-agent` 后，开始工作时仍须核对设计依据、授权和前置交付。需要人类选择的任务应提供可评估的方案与问题；已有设计未覆盖的行为先进入设计讨论。

创建、阅读、认领和记录结果的步骤见 [轻量任务文档](issue-tracker.md)。
