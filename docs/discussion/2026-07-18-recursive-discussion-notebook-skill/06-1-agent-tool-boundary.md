# D6.1：Agent 与工具的职责边界

> 状态：`已确认`
>
> 产出：[结论汇总](conclusions.md)
>
> 父主题：[D6 维护与检查](06-maintenance.md)

## 当前结论

工具只检查不理解讨论含义也能确定的文件事实；Agent 判断讨论含义；用户掌握语义确认权。

## 工具可以检查

- 断裂的 Markdown 链接；
- 缺失或非法的讨论状态；
- 父子导航明显不一致；
- `已取代`状态缺少来源链接；
- 页面达到容量警报值；
- 没有被枢纽页收录的疑似孤立页面。

容量警报和疑似孤立页面只是审查提醒。工具不能据此断言页面必须拆分或删除。

## Agent 必须判断

- 页面是否包含多个独立问题；
- 摘要是否准确；
- 反例是否构成质疑；
- 质疑是否已经解决；
- 新方案是否真正取代旧方案；
- 历史推理是否仍需保留。

只有用户可以确认讨论语义，或者批准草稿内容迁移为正式设计。工具不能根据关键词升级状态。

工具输出至少区分“可以客观证明的错误”和“需要 Agent 判断的审查提醒”。检查全绿只说明没有发现机械损坏，不能证明内容正确。

这类检查保护草稿网络的结构完整性，不规定作者必须使用哪些句子，也不是对自然语言做逐字测试。
