## 当前结论

不为 skill 的自然语言内容建立固定措辞、固定标题或全文快照测试。采用人工阅读、真实场景试用和附带程序验证三类证据。

## 人工阅读

检查：

- 规则是否通俗、相互一致；
- 是否把临时草稿误写成正式规范；
- 是否为了机器处理强加无实际价值的字段或模板；
- 人类能否在 Obsidian 中自然阅读。

## 真实场景试用

使用 skill 拆分和维护真实长讨论，并让没有参与先前讨论的新 Agent 从索引开始恢复。观察它能否：

- 找到当前讨论页；
- 区分已确认、当前提案、已取代和未解决质疑；
- 准确指出下一步；
- 不加载整个草稿网络；
- 不把旧提案当成当前结论；
- 在独立分支出现时及时拆分；
- 避免为每个微小追问建立新文件。

结果由人类阅读和实际恢复效果判断，不以生成文本与标准答案逐字一致为通过条件。

## 附带程序验证

如果 skill 包含断链或结构检查脚本，脚本作为普通程序验证其报告是否正确。程序测试不检查 skill 或草稿的自然语言措辞。
