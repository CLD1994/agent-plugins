## 当前结论

第一版正式关系只保留五组：

1. **父主题 / 子主题**：说明页面在讨论结构中的归属。
2. **依赖于 / 被依赖**：说明理解或修改一个结论前必须先确认的前置结论。
3. **取代 / 被取代**：区分当前方案与作为历史保留的旧方案。
4. **质疑 / 被质疑**：记录尚未解决、但已经威胁当前方案或已确认结论的反例与对抗式审查；它不自动撤销结论的当前效力。
5. **产出 / 来源于**：由已经确认且当前未被取代的草稿页指向草稿网络内的结论汇总产出页；产出页概括这些结论并链接回来源，供后续流程渐进读取。它本身不授予正式批准状态。

普通 Markdown 跳转链接仍可自由使用，但不必归入正式关系。

第一版不提供“相关于”这种含义模糊的正式关系，以免记忆图被大量低信息链接淹没。
