## 结论

**FAIL — 5 findings。** 最严重的是 F4：`collapse` 的目录清理可与“本地资源不归页面所有”冲突，存在删除独立资源的合同缺口。

已闭合：candidate/registered 的总体门禁、生成器拥有的 `conclusions.md` 链接例外、两类 Markdown 的 Links/Backlinks、Restore 七分区，以及 runtime 锁/恢复/handoff 未泄入领域合同。

## Findings

### F1 — 高：`ResourceIdentity` 没有可复核的词法合同

**位置/触发**：合同 §3.1--3.3（115--159）、§10.1（361--368）。相同资源用 `..\\x`、混合分隔符、盘符/UNC、盘符相对路径或相对 Backlinks target 表达时，Links、Backlinks 与 move 的映射可各自得出不同 identity。

**规格/根因/不变量**：票据工作决策第 8 条（24 行）要求统一 CommonMark + `ResourceIdentity`；已批准设计 2026-08-10 §7.1--7.4、§8.3（162--249、300--310）保留这些词法类别和 Backlinks 的根基准。现文仅给结果枚举，未给目标语法、source/request 基准、规范化和不可解释分类；违反“同一链接事实只有一个 identity 判定”。

**已确认合同/建议边界**：补齐共享 identity 的输入分类、基准与比较规则；同时声明 CommonMark 提取覆盖的链接形式。保留 `invalid`/`unavailable` 的语义差异，不固定 JSON 字段或平台实现。实现应只在共享 extractor/identity resolver，供 Links、Backlinks、计数和四个结构命令调用。

**范围/验证/前提**：审计 move/promote/collapse/Trash、Page 计数和所有链接读；用上述路径矩阵、图片/引用链接和同批交叉链接证明同一 identity 与重写结果。未核验：后续 ABI 可选择字段名，但不得重定义分类。

### F2 — 高：页面纳管后的协议欠账没有逐命令门禁

**位置/触发**：合同 49、170--178、223、231--248、252--275。candidate 中把只有正文的 `legacy.md` 纳管为 `pages/x.md` 后，`promote x y` 只要求 child 可解析，未要求 x 或共同父导航可解析，却要求“保持页面状态/导航”。

**规格/根因/不变量**：票据第 4、10 条（20、26 行）禁止推断机器事实；已批准 2026-08-12 §9.1（381--391）逐命令列出 source、父页、导航、关系图的可判定前提。现文把“路径已受管理”和“可安全机械编辑”混为一类；违反未知不得当作可维护协议。

**已确认合同/建议边界**：页面纳管仍只搬原 Markdown 并改正文链接，Check 报债务。补一张 operation-fact 表：已纳管但不完整的页可供 Links/Backlinks/Check；任何要读写其标题、机器区域、父导航或正式关系的命令，先证明对应部分可解析，否则零写拒绝，绝不补猜。由 shared operation preflight 执行，而非让 Check 代替门禁。

**范围/验证/前提**：已知入口为 managed move、promote、collapse、status、relation、Trash/Restore；分别以缺标题、缺状态、缺父导航的已纳管页作 Execute/DryRun，验证拒绝且字节不变，修复后成功。未核验：精确错误码留给公共 ABI。

### F3 — 高：collapse 没有定义叶/枢纽目标占用

**位置/触发**：合同 §5.4（246--248）。candidate 中 `pages/x.md` 与空 `pages/x/index.md` 同时存在时，collapse 的已列前提满足，却未说明目标 `pages/x.md` 的占用处理；同一缺口进入 move/Trash 自动 collapse。

**规格/根因/不变量**：2026-08-12 §2.3（61--72）禁止静默覆盖，§9.1 collapse 行（386）要求不丢失页面。现文只在 promote 写了目标占用拒绝，未把叶/枢纽替换纳入统一 namespace-occupancy 判定；违反“不覆盖既有节点”。

**已确认合同/建议边界**：转换前必须认证 after-path 未占用；否则整批零写冲突。合同还须明确“双表示”是 Check error，或允许其存在但一切转换拒绝；无论选择，不能覆盖。以一个 page-tree occupancy resolver 供 create/promote/collapse、自动 collapse 与 Restore 共用。

**范围/验证/前提**：回归 explicit/automatic collapse、promote、Restore 的文件/目录/符号链接/同名页组合，断言原字节保留。未核验：双表示是否应作为独立 Check error，需在合同中选择。

### F4 — 高：独立本地资源与 collapse 目录删除相矛盾

**位置/触发**：合同 60、223、246--248、310、320、335。`pages/x/index.md` 无子页但有 `pages/x/figure.png` 时，collapse（或 move/Trash 引发的自动 collapse）可按“移除目录”删除不属于页面的资源。

**规格/根因/不变量**：票据第 13 条（29 行）规定结构命令、Trash、Restore、handoff 仅处理受管理 Markdown；资源原位保持。现文已声明无资源所有权，却未定义物理目录残留规则；违反“不得因目录位置取得或删除资源”。

**已确认合同/建议边界**：collapse 只移动 Markdown；仅当物理目录确实为空才移除，否则保留目录及资源。promote 使用既有资源目录时也不得搬移、删除或认领资源；若安全创建 index 不能证明则拒绝。将规则置于共享 path-mapping/cleanup 边界，runtime 只负责 no-follow/durability。

**范围/验证/前提**：覆盖 explicit/automatic collapse、promote、Trash、Restore 与 handoff 包；含图片、附件和子目录，验证 identity/字节不变。未核验：允许使用既有资源目录的细节仍须合同明确，但“不删除/不认领”已确认。

### F5 — 中：目录 move 的 retained facts 不可判定

**位置/触发**：合同 §5.2（225）。移动含大量嵌套非 Markdown 内容的目录时，“有界 retained facts”未规定所列事实的身份、排序、总量/截断，因此调用方无法判断哪些内容确实留在原树。

**规格/根因/不变量**：票据第 5 条（21 行）要求结果向调用方暴露有界 retained facts。现文把它写成愿望而非结果合同；违反结果必须可让 Agent 据事实继续整理。

**已确认合同/建议边界**：结果须语义上给出每个已报告 retained 资源的根内 identity 与“原位保留”事实，并给出 total/截断（或等价的有界遍历）以区分空、完整和截断；字段名、页大小和编码留给 ABI。由 move result projection 从已认证枚举派生，不重新扫描或推断所有权。

**范围/验证/前提**：目录含 Markdown、嵌套图片/普通文件/空目录时，验证移动映射、资源不动、稳定有界 facts 与截断事实。未核验：上限和分页形态尚未获批准。
